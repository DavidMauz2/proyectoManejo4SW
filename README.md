# NEXUS SOFTWARE — Página web de una empresa ficticia

## Archivos
- `index.html`: estructura de la página y sus cinco secciones.
- `styles.css`: diseño visual adaptable a escritorio, tablet y móvil.
- `script.js`: menú móvil, navegación activa, año del footer y validación de demostración del formulario.

## Cómo ejecutar
1. Descarga y descomprime el proyecto.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes usar la extensión Live Server.

## Reparto de secciones
1. Integrante 1: `#inicio` — lenguajes de programación.
2. Integrante 2: `#servicios` — sistemas y soluciones digitales.
3. Integrante 3: `#proceso` — proceso de desarrollo.
4. Integrante 4: `#tecnologias` — tecnologías e infraestructura.
5. Integrante 5: `#contacto` — empresa, misión, visión, valores y contacto.

## Notas
- El sitio utiliza HTML, CSS y JavaScript sin frameworks.
- Los logotipos de lenguajes se cargan desde Devicon y la tipografía desde Google Fonts; se requiere conexión a Internet para esos recursos externos.
- El formulario solo valida los campos en el navegador. No envía correos ni almacena información. Para recibir mensajes reales se necesita conectarlo a un backend o servicio de formularios.
- NEXUS SOFTWARE, sus datos de contacto y su ubicación se presentan como contenido ficticio.
